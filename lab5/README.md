## Описание

Веб-страница новостного портала, разработанная с использованием семантических элементов HTML5 и современных возможностей CSS3.

### Реализованные требования:

1. **Семантика:** использованы теги header, nav, main, section, article, aside, footer, figure, figcaption, time, address, form, label, input, button.
2. **CSS3 эффекты:**
   - transition и transform (поднятие карточек при наведении, масштабирование кнопок).
   - Псевдоэлементы ::after (декоративная линия под заголовком) и ::before (кастомная нумерация списка).
   - box-shadow и border-radius для карточек и блоков.
   - Градиентные фоны.
3. **Адаптивность:** Media query перестраивает сетку в одну колонку на мобильных устройствах.
4. **Структура:** Внешний файл стилей, корректные alt у всех изображений.
